# bloblings.io

The website for **Bloblings**, a tiny colony sim for Android.

- `index.html` — the landing page, including the Updates section
- `beta.html` — orientation and the feedback questionnaire for closed testers
- `icon.png` — the app icon

Both pages are self contained: no build step, no dependencies, no tracking. Open either
one straight from disk to preview it.

## Posting an update

Copy the first `<article class="post">` block in `index.html`, paste it above the one you
copied, and change the date, the title and the text. Nothing else needs editing.
